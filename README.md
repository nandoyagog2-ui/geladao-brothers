# Geladão Brothers

Cardápio digital e painel de gestão.

- **Cardápio do cliente:** `/` (index.html)
- **Painel (com login):** `/painel`
- **Banco:** Supabase. Os scripts ficam em `sql/`.
- **Ligação com o banco:** `js/config.js` (só a chave pública).

Site estático: não precisa de build. A Vercel publica direto do GitHub.
